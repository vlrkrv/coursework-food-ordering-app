# Вебзастосунок замовлення страв

Курсова робота з дисципліни «Веб-технології та веб-дизайн». Являє собою вебзастосунок для автоматизації прийому замовлень у закладі харчування з контролем пропускної здатності часових інтервалів (ліміт замовлень на часовий слот).

## Технологічний стек

- **Серверна частина:** Node.js, Express.js
- **База даних:** PostgreSQL
- **Шаблонізатор:** EJS
- **Аутентифікація:** express-session, bcryptjs
- **Тестування:** Jest, Supertest

## Вимоги до середовища

Для запуску проєкту необхідно мати встановлені:
- **Node.js** (версія 18 або вище)
- **PostgreSQL** (версія 14 або вище)
- **Git** (для клонування репозиторію)

## Інструкція зі встановлення та запуску

### 1. Клонування репозиторію

Склонуйте репозиторій на свій комп'ютер та перейдіть у папку проєкту:

git clone https://github.com/vlrkrv/coursework-food-ordering-app.git
cd food-app

### 2. Встановлення залежностей

Виконайте команду для завантаження всіх необхідних бібліотек, вказаних у package.json (Express, EJS, pg, bcryptjs, express-session, dotenv, а також dev-залежності nodemon, jest, supertest):

npm install

### 3. Налаштування бази даних

Створіть базу даних у PostgreSQL (наприклад, через pgAdmin або командний рядок):

CREATE DATABASE food_ordering;

Створіть файл .env у корені проєкту (на основі прикладу .env.example) та вкажіть свої дані:

env
PORT=3000
DATABASE_URL=postgresql://postgres:ПАРОЛЬ@localhost:5432/food_ordering
SESSION_SECRET=секретний_рядок

### 4. Створення схеми даних та наповнення бази

Застосуйте SQL-схему для створення таблиць та заповніть базу тестовими даними (страви, слоти, користувачі):

psql -U postgres -d food_ordering -f src/schema.sql
node src/seed.js

### 5. Запуск сервера

Запустіть сервер у режимі розробки (з автоматичним перезапуском через nodemon):

npm run dev

Після цього застосунок буде доступний у браузері за адресою: http://localhost:3000

### Тестові облікові записи

Після виконання скрипта seed.js у базі створюються два користувачі:

Відвідувач: visitor@test.com / пароль: 123456

Оператор: operator@test.com / пароль: 123456

### Запуск тестів
Для перевірки працездатності бізнес-логіки та захисту доступу передбачено набір автоматизованих тестів (Jest + Supertest). Виконайте команду:

npm test

### Структура проєкту

**server.js** — точка входу, налаштування Express та сесій.

**src/db.js** — підключення до PostgreSQL.

**src/routes/** — маршрути (автентифікація, меню, кошик, замовлення, оператор).

**src/services/orderService.js** — бізнес-логіка створення замовлення (транзакції, перевірка лімітів).

**src/middleware/auth.js** — перевірка прав доступу.

**src/schema.sql** — SQL-скрипт створення таблиць.

**src/seed.js** — скрипт наповнення бази.

**views/** — EJS-шаблони сторінок.

**public/style.css** — стилі інтерфейсу.

**tests/api.test.js** — автоматизовані тести.
